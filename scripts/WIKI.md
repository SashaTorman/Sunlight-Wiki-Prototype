# Внутренние страницы Wiki

Все карточки разделов, логотипы брендов на главной, поиск и «Читайте дальше»
открывают материалы на том же ресурсе и в той же вкладке.
«Ювелирное дело» сохраняет гиперссылки на uvelirnoedelo.ru.
Ссылки на товары, магазин и служебные разделы SUNLIGHT сохраняют своё назначение.

Добавлены полные статьи из прежнего прототипа и публичных страниц SUNLIGHT,
включая иллюстрации. Содержимое вставлено в текущий шаблон с существующими
шапкой, поиском, оформлением статей, подвалом и подборками товаров.
Прежние скрипты и виджеты исходных сайтов не импортируются.

Бренды, термины, книги и «Мир SUNLIGHT» используют существующие локальные
шаблоны `article/brand.html#...`, `article/term.html#...`, `article/book.html#...`
и `article/mir.html#...`. Данные и фотографии этих страниц уже находятся в проекте.

`data/article-sources.json` содержит список импортированных страниц и их источники.
Одна устаревшая ссылка внутри текста о серебре возвращала 404 на источнике;
её текст сохранён, неработающая гиперссылка снята.

## Проверка

```sh
python3 scripts/check-wiki-links.py
```

Проверяет внутренние ссылки и изображения во всех HTML-страницах, адреса
838 записей поиска, существование выбранных брендов/терминов и актуальность
версии поискового индекса. Версия в URL индекса предотвращает использование
сохранённых в браузере результатов со старыми внешними ссылками.

## Перенос дополнительных материалов

```sh
python3 scripts/localize-wiki.py /absolute/path/to/sunlight-wiki-source.zip
python3 scripts/import-linked-articles.py
```

Скрипты сохраняют существующие тексты страниц. Первый переносит недостающие
страницы из архива прежнего прототипа и по прямым ссылкам из индекса, второй —
статьи, на которые ссылается основной текст. Оригиналы для повторного запуска
кэшируются во временной папке. Для чтения публичных источников нужен интернет.
