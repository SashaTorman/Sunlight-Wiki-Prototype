# Подборки SUNLIGHT в прототипе

Блок выводит пять разных товаров после статьи, перед «Читайте дальше».
Карточки ведут на товары, «Смотреть ещё» — в соответствующий раздел каталога.
На узких экранах все пять карточек доступны в горизонтальной ленте.

## Где включён блок

Страницы подключают `assets/catalog-recommendations.js` с атрибутом
`data-catalog-topic`. Тема выбирается явно для обычной статьи; значение `term`
подбирает тему по заголовку термина в словаре и обновляет блок после загрузки
нового термина. Упоминания украшений в тексте биографии не включают подборку.
Персоны, книги, истории брендов и корпоративные страницы блок не подключают.

Новая статья подключает рядом с основным CSS:

```html
<link rel="stylesheet" href="../assets/catalog-recommendations.css">
<script src="../assets/catalog-recommendations.js" data-catalog-topic="chains" defer></script>
```

Доступные темы перечислены в `data/catalog-products.json`. Для новых терминов
правила находятся в `termRules` общего скрипта. Тема без подходящих товаров
не заменяется случайной подборкой.

## Данные и обновление

`data/catalog-products.json` — сохранённые публичные данные каталога: названия,
бренды, цены, прямые ссылки и исходные адреса фотографий. Фотографии хранятся
локально в `img/catalog/`. Это снимок каталога для макета; цены и наличие
не обновляются при каждом просмотре страницы.

Обновление из корня репозитория, с доступом к интернету:

```sh
python3 scripts/update-catalog-products.py
```

Скрипт читает публичные страницы SUNLIGHT, получает адреса фильтров из самого
каталога и выбирает по пять разных доступных для заказа товаров. Подборки,
где нет пяти товаров, пропускаются. Новые фотографии берутся уменьшенными
с CDN; уже сохранённые файлы повторно не скачиваются. Файл данных записывается
после успешной загрузки всех фотографий.

На момент сборки макета для нефрита нашлось два доступных товара, для
натурального опала — три, поэтому эти подборки не включены. Для публикации
с постоянно актуальными ценами потребуется интеграция с товарным фидом
или серверным API каталога.
